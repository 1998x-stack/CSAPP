## 集成验证命令

要求 Linux x86-64、CMake 3.20+、Python 3.9+、GCC 或 Clang、GNU binutils（`ar`、`nm`、`readelf`、`objdump`）。POSIX 进程、信号和 Linux `mmap` 示例仅在支持的平台构建。

```bash
python3 scripts/audit_sources.py --check
python3 -m unittest discover -s tests -p 'test_m08_*.py' -v
cmake -S . -B build/m08 -DCMAKE_BUILD_TYPE=Debug -DCSAPP_ENABLE_UBSAN=ON
cmake --build build/m08 --parallel 2
ctest --test-dir build/m08 --output-on-failure
python3 scripts/m08_inspect_linker.py
python3 -m unittest discover -s tests -v
```

## 可观察的 ELF 证据

`scripts/m08_inspect_linker.py` 单独执行类似以下命令（输出全部放入 `build/m08-link-inspect/`）：

```bash
nm -u build/m08-link-inspect/main.o
nm -g --defined-only build/m08-link-inspect/libm08arith.a
ar t build/m08-link-inspect/libm08arith.a
readelf -r build/m08-link-inspect/main.o
readelf -h build/m08-link-inspect/m08_linker
objdump -d build/m08-link-inspect/m08_linker
```

通过这些文件观察未定义符号如何经静态归档解析和重定位，再连接生成 ELF；这个过程比仅在源代码中演示 `#include` 更接近链接器真实行为。
